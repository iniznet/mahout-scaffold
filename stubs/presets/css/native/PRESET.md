# CSS preset: native

Modern CSS only: `@layer`, nesting, custom properties, `clamp()`, container
queries, `:has()`, `color-mix()` and `light-dark()`. The preset adds no
dependency and no build step beyond the theme's own Vite run; the stylesheet
is the one in `resources/css/app.css` and the tokens stay in the shared
`resources/css/tokens.css`.
